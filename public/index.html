아직 사무실에 아무도 없어요. 최근 24시간 안에 움직인 Claude Code 세션이 여기 책상에 앉아요. 처음이라면:
  1. claude-office 폴더에서 node install.mjs (hook 설치, ~/.claude/settings.json은 백업 후 수정)
  2. CLAUDE-report-rule.md 내용을 ~/.claude/CLAUDE.md 끝에 붙이기 (턴 끝에 결재 보고를 쓰게 하는 규칙)
  3. Claude 데스크톱 앱에서 세션을 열고 작업을 지시하기 → 사원이 출근해요

hook 기록이 아직 하나도 없어서 사원 상태(작업 중·보고·막힘)를 알 수 없어요. claude-office 폴더에서 node install.mjs를 실행한 뒤, 세션에서 메시지를 한 번 보내 보세요.
