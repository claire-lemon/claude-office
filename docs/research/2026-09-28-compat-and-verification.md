# 호환성 · 검증 상태 조사 (2026-09-28)

## 1. 목적

1. Claude Office가 macOS·Windows에서 동작하는지 확인
2. 지금까지의 검증이 어디까지 실제로 확인된 것인지, 남은 이슈가 무엇인지 정리

## 2. 조사 방법

1. OS 의존 코드 전수 검색: `open`, `pbcopy`, 앱 데이터 경로, 경로 구분자, `rename`, 셸 명령
2. 독립 코드 리뷰: 작성자가 아닌 별도 에이전트가 읽기 전용으로 버그·보안·검증 공백 조사, 가능한 항목은 재현
3. 검증이 비어 있던 기능 실행: "요약 만들기"(`claude -p`)를 가짜 데이터로 실제 호출
4. 조사 환경: macOS 26.4.1, Node v22.15.1, Claude Code CLI 2.1.206, git 2.52.0. Windows 실기기는 없어서 **Windows 항목은 코드 읽기 기준**

## 3. 사실

### 3.1 플랫폼 호환성

| 항목 | 위치 | macOS | Windows |
|---|---|---|---|
| 앱 세션 메타데이터 경로 | `lib.mjs:8` | 동작 | macOS 경로 하드코딩 → 세션 제목·브랜치·PR·딥링크를 못 읽음. Windows 앱의 실제 경로는 **미확인** |
| 세션 상태(hooks) | `hooks/report.mjs` | 동작 | 코드상 OS 의존 없음. hook 명령(`install.mjs:24`, `node "<경로>"`)이 Windows hook 실행 셸에서 동작하는지 **미확인** |
| hooks 설치·제거 마커 | `install.mjs:11` | 동작 | 마커가 `/` 구분자 문자열 → Windows 경로(`\`)와 불일치 → 재설치 시 중복 추가, `--uninstall`이 제거 못 함 (코드 읽기로 판단, 실행 미확인) |
| 채팅방 열기 · 딥링크 | `server.mjs:51` (`open`) | 동작 | `open` 명령 없음 → 조용히 실패 |
| 컨펌 지시문 복사 | `server.mjs:55` (`pbcopy`) | 동작 | `pbcopy` 없음 → 조용히 실패 |
| 경로 `~` 줄임 | `lib.mjs:36` | 동작 | `\` 구분자라 줄이지 못함 (표시만 영향) |
| hooks 설치 전 세션의 대화 기록 경로 추정 | `lib.mjs:74` | 동작 | Windows의 폴더 이름 규칙 **미확인**. hooks 설치 후 세션은 hook이 경로를 직접 주므로 영향 없음 |
| 상태 파일 원자적 쓰기 | `hooks/report.mjs:38`, `lib.mjs:33` | 동작 | 대상 파일을 다른 프로세스가 열고 있으면 rename이 실패할 수 있음 (**추측**). hook은 오류를 삼키므로 그 이벤트 하나가 누락됨 |
| `claude://` 딥링크 (`/epitaxy/<id>`, `/code/new?q=`) | `lib.mjs`, `server.mjs` | 동작 (새 세션 입력창 채우기는 사용자 확인) | Windows 앱이 같은 스킴·경로를 지원하는지 **미확인** |
| 테스트 | `test/core.test.mjs:74` 등 | 19개 통과 | `/` 구분자 비교, shebang 가짜 `claude` 스크립트 → 일부 실패 예상 |

결론: **현재는 macOS 전용.** Windows에서는 상태 추적(hooks)만 동작할 가능성이 있고, 제목·딥링크·클립보드·설치 제거가 깨진다. Linux는 Claude 데스크톱 앱 지원 여부가 확인되지 않아 대상에서 제외.

### 3.3 독립 리뷰에서 문제없다고 확인된 항목

1. 정적 파일 경로 조작(`../`) 차단 (`/../../../etc/passwd` → 404)
2. hook의 `session_id`를 파일 이름으로 쓰기 전 정제
3. `execFile` 인자 배열 사용 → 셸 명령 주입 없음
4. 프론트엔드 XSS: 마크다운 렌더러가 이스케이프 후 변환, 세션 문자열은 `textContent` 사용
5. `decisions.json` 쓰기는 단일 프로세스 동기 처리라 서버 안에서 경합 없음

### 3.5 남은 알려진 이슈

1. hooks가 전역이라 이 컴퓨터의 **모든** Claude Code 세션이 보드에 올라온다. 터미널 CLI 세션, 예약 작업의 `claude -p` 실행도 포함. 데스크톱 앱 세션만 골라내는 규칙은 없음
2. 앱 세션 메타데이터는 공개 API가 아닌 내부 파일이라 앱 업데이트로 바뀔 수 있음
3. 결정과 hook 이벤트가 같은 밀리초에 기록되면 결정이 무시됨 (`lib.mjs`의 `activeDecision`이 `>` 비교). 실사용에서 발생 가능성 낮음 (리뷰 에이전트, 재현 안 함)
